# FID-20260912-083 — Player Info VIP row: real status, inline icon

## Operator report

"In the player info, I see 'active' and a crown for the VIP even though I have active VIP —
it should show the VIP status there, and the icon should be in line, not above it."

## Two defects in the Player Info VIP row

1. **No actual status.** With active VIP the row rendered a bare "Active" — no expiry, no
   time remaining — even though `player.vipExpiration` was already in the panel's data.
2. **Crown icon wrapped above the text.** The value cell (`nn-row__value`, right-aligned,
   narrow) received `<Crown /> Active` as loose inline content. Under width pressure the
   SVG and the text wrapped independently, stacking the crown on its own line above
   "Active".

## Fix (components/StatsPanel.tsx)

- **Status text**: computes remaining time from `vipExpiration` — `Xd Yh` (or `Yh` under a
  day) — and renders `👑 Active · 11d 4h`. Falls back to plain "Active" if no expiry is
  present. Hover title shows the exact expiry timestamp.
- **Inline icon**: the button is `inline-flex; align-items: center; gap: 4px;
  white-space: nowrap`, and the crown SVG is `flex: none` — the pair can never wrap or
  split, the icon stays in line with the label at any panel width.

## Context

144 component files built independently with zero design system:
- Font sizes from `text-[9px]` to `text-20rem` — no hierarchy
- Competing `bg-gray-*` vs `bg-slate-*` with no rules
- Border opacities `/15` through `/60` — no semantic meaning
- 15+ unique glow shadow values in TileRenderer alone
- Gray-on-dark text (`text-gray-400/500`) — unreadable
- Emoji at `text-6xl`, `text-[4rem]`, `text-[20rem]` — absurd
- Two competing design systems: raw Tailwind vs semantic `ui/` tokens

This FID establishes a proper theming system with a single source of truth, applies it across the main game UI (19 files), and architects for a future light theme.

## Official Color Palette: NEON SYNTH INTERFACE

| Token | Hex | CSS Variable | Tailwind Token | Usage |
|-------|-----|-------------|----------------|-------|
| Void Indigo | `#02010A` | `--void` | `synth-void` | Page background |
| Arcane Shadow | `#1E1E2E` | `--shadow` | `synth-shadow` | Card/panel backgrounds (pure) |
| System White | `#FFFFFF` | `--white` | `synth-white` | Primary text |
| Electric Blue | `#007FFF` | `--electric` | `synth-electric` | Active states, links, coordinates |
| Neon Pink | `#FF1493` | `--neon-pink` | `synth-pink` | Critical alerts, special |

| Synth Green | `#00FF00` | `--synth` | `synth-green` | Success, resources, active |
| Neon Yellow | `#F2FF00` | `--neon-yellow` | `synth-yellow` | VIP, power, intermediate |

### Text Hierarchy — White Opacity Scale ONLY

| Level | Class | Usage |
|-------|-------|-------|
| Primary | `text-white` | Names, values, key data, body |
| Secondary | `text-white/70` | Labels, descriptions |
| Tertiary | `text-white/40` | Hints, timestamps |
| Faint | `text-white/25` | Placeholders, disabled |

**NO `text-gray-*` for body/label text. Ever.**

### Font Size Scale — 5 Steps ONLY

| Class | Size | Usage |
|-------|------|-------|
| `text-xs` | 12px | Body, table cells, descriptions |
| `text-sm` | 14px | Values, section headers (bold) |
| `text-base` | 16px | Inline emoji, key numbers |
| `text-lg` | 18px | Coordinates, major values |
| `text-xl` | 20px | Page titles only |

**No arbitrary pixels.** **No `text-2xl`+ except page titles.** Section headers are `text-sm font-bold`.

### Emoji Sizing — 4 Steps ONLY

| Context | Class |
|---------|-------|
| Inline with text | `text-base` |
| Section header icon | `text-sm` |
| Status badge | `text-lg` |
| Feature/card icon | `text-xl` |

**No emoji larger than `text-xl`.** Delete all `text-2xl`, `text-3xl`, `text-4xl`, `text-6xl`, `text-[4rem]`, `text-[20rem]`.

### Glow System — Box Shadow Only (NEVER text-shadow)

3 intensity tiers. Color matches semantic meaning:

| Intensity | Shadow | Usage |
|-----------|--------|-------|
| Subtle | `0 0 8px rgba({color}, 0.15)` | Inactive cards, subtle borders |
| Standard | `0 0 12px rgba({color}, 0.25)` | Active cards, hover states |
| Strong | `0 0 16px rgba({color}, 0.35)` | Critical alerts, key buttons |

**NEVER** `text-shadow`, `drop-shadow-*`, `blur-sm` on glow orbs, animated glow layers, or `box-shadow` with spread >16px. No `shadow-[0_0_20px_...]` or larger.

### Border System — Semantic Neon at Low Opacity

| Context | Border |
|---------|--------|
| Default card | `border border-white/10` |
| Interactive | `border border-[color]/25` |
| Success | `border border-[--synth]/25` |
| Danger/combat | `border border-[--neon-red]/30` |
| Warning/flag | `border border-[--solar]/30` |
| VIP/power | `border border-[--neon-yellow]/30` |
| Critical | `border border-[--neon-pink]/30` |
| Divider | `border-white/5` to `border-white/10` |

**No `border-gray-*` or old palette references.**

### Card Chrome

```
Background:   bg-[--shadow]  (pure #1E1E2E)
Border:       border border-white/10  (or semantic variant)
Radius:       rounded-lg  (8px)
Content pad:  p-2.5  (10px)
Wrapper pad:  p-3    (12px)
Inner space:  space-y-1.5 to space-y-2
```

### Card Header Banner

```
background: linear-gradient(to right, from [semantic-color]/10, to transparent)
padding:    px-3 py-1.5
text:       text-sm font-bold text-white
border-b:   border-white/10  (or semantic variant)
```

### Table Pattern

```
Even row:     bg-white/[0.03]
Odd row:      bg-white/[0.06]
Cell:         px-2.5 py-1 text-xs
Header cell:  bg-white/[0.05] text-white/50 font-medium
```

## Theme Architecture

### CSS Custom Properties (`app/globals.css`)

All 9 colors defined under `:root`. Light theme redefines under `.light` class — no component changes needed.

### Tailwind Integration (`tailwind.config.ts`)

`theme.extend.colors` updated with `synth-*` tokens replacing old `neon.*`. `boxShadow` updated with 3 glow tiers per semantic color. Old `neon.cyan/blue/purple/pink/green/yellow` removed. `pulseGlow` keyframes updated to use new palette.

### Light Theme Preparation

1. All colors via CSS custom properties — no hardcoded hex in components
2. `.light` class on `<html>` redefines all `--*` variables
3. Opacity values for text hierarchy adjust for light backgrounds
4. Light theme FID = only CSS variable redefinition, zero component changes

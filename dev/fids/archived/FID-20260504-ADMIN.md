## Context
The admin panel (`app/admin/page.tsx`, 3374 lines) was built for MongoDB but migrated to Supabase. The TypeScript interfaces (`AdminStats`, `PlayerListItem`) used field names from the old MongoDB schema that don't match the current API responses. Several features called API routes that never existed or existed at wrong paths. The `bot-spawn` and `bot-regen` buttons returned simulated/stub responses (ECHO violation).

## Issue: Admin Panel Shows Available Features That Are Broken or Missing Backend

### Symptoms
- Stats dashboard showed zeros/undefined (interface mismatch)
- Player management table tried to render `p.metal`, `p.energy`, `p.baseLocation` — none exist in API
- "Spawn 10 Bots" and "Run Regen Cycle" buttons did nothing useful (simulated responses)
- Player detail modal showed "Error loading player data"
- Tile inspector crashed with "Objects are not valid as a React child"
- Session distribution chart always empty (JSON parsing bug)
- Map distribution section showed stats from a non-existent `mapStats` field
- 8 API routes were missing entirely

### Root Cause Analysis
1. **Interface drift:** `AdminStats` and `PlayerListItem` interfaces were never updated when the API response format changed during Supabase migration
2. **Route gaps:** PlayerDetailModal called `/api/admin/anti-cheat/ban`, `/api/admin/anti-cheat/unban`, `/api/admin/anti-cheat/player-flags` — none existed
3. **Simulated data:** `bot-spawn` and `bot-regen` routes returned fake success without real DB operations (direct ECHO violation)
4. **Rendering bugs:** `sessionJson` vs `sessionJson.data`, object values passed as React children
5. **Missing backend:** `player-tracking/sessions`, `player-tracking/activity` tables never migrated

## Context

The chat system (ChatPanel.tsx, 2297 lines) was built by a different agent with zero design system consistency. It used:
- Old cyan/blue/gray palette colors throughout
- `bg-black` instead of `bg-[--card]`
- `border-white/10` instead of `border-[--border]`
- `text-cyan-400`, `text-gray-400`, `text-yellow-400`, `text-blue-400`, `text-purple-400`, `text-red-400` — all old palette
- `bg-cyan-500/20`, `border-cyan-500/50` — old neon colors
- Inconsistent spacing and padding
- No shared design system tokens

---

## Changes Applied

### ChatPanel.tsx — Complete Rewrite
- Replaced `bg-black` with `bg-[--card]`
- Replaced `border-white/10` with `border-[--border]`
- Replaced all `text-cyan-400` with `text-[--electric]`
- Replaced all `text-gray-400/500` with `text-[--text-2/3]`
- Replaced all `bg-cyan-500/20` with `bg-[--electric]/10`
- Replaced all `border-cyan-500/50` with `border-[--electric]/25`
- Replaced all `bg-gray-800/50` with `bg-white/[0.03]`
- Replaced all `text-yellow-400` with `text-[--neon-yellow]`
- Replaced all `text-blue-400` with `text-[--electric]`
- Replaced all `text-purple-400` with `text-[--neon-pink]`
- Replaced all `text-red-400` with `text-[--neon-red]`
- Removed `backdrop-blur-xl` and holographic effects
- Used consistent `text-[13px] font-bold` for headers
- Used consistent `text-xs` for body text
- Used `bg-[--row-even]`/`bg-[--row-odd]` for table rows
- Emoji-sized flag icon (⚑) with proper brightness filter

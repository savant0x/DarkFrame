## Root-Cause Summary

Two interlocking failures across vite 8.0.3 × vitest 4.1.2 on Node
25.2.1/Windows:

1. **toBuiltin() contract break:** vite externalizes node builtins to the
   bare stub `__vite-browser-external`; vitest 4.1.2's reverse-mapper strips
   it via `slice(24)` → `""` → literal `node:` → Node rejects. The `node:`
   prefix does **not** bypass externalization (confirmed: the warning names
   it either way). Affected: ALL node-builtin imports under jsdom, including
   setup files.

2. **Dead polyfill in vitest.setup.ts:** bare `import ... from 'util'` for
   TextEncoder/TextDecoder that could never install (Node ≥11 globals; jsdom
   does not remove them). Its presence poisoned every jsdom worker.

3. **25 server-side test files lacked per-file `@vitest-environment node`:**
   their import chains (pg, drizzle, mongodb, socket.io) hit the same crash
   once the setup barrier was removed.

4. **Hardcoded ISO week 37 in beerBaseScheduler.test.ts:** stale after 8pm
   ET (UTC rolls to week 38) → dedup never matches → mock crashes.

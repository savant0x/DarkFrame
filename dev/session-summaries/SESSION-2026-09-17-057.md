`relation "blocked_users" does not exist` (pg 42P01): **every report and block
call in the running game was a guaranteed 500.**

  the drizzle definitions (columns, `blocked_pair_unique`, indexes).

  verification, explicit exit. Applied: exit 0, columns match exactly.

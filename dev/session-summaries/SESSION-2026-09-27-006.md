### The shell ate row 139

Appending the ledger row via `node -e "…"` with double quotes let bash perform command
substitution on every backtick in the text: **11 code spans were destroyed** — `@ts-nocheck`,
`DATABASE_URL`, `implemented`, `lib/websocket/` and more, silently replaced with empty strings.

**The census passed it.** Row 139 has correct pipes, so check F was satisfied, the row counted,
and Gate 7 printed clean over a row with holes in its middle. Rewritten with the shell-safe form
(single-quoted script, literal backticks) and verified by extracting the code spans back out.

That is the third time this class of defect has appeared in one session and the first time a gate
passed straight through it. The lesson generalises: **a shape check cannot see missing content.**
Check F counts delimiters; it does not know what the row was supposed to say. The row was caught
only by reading it back.

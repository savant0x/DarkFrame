## Infantry system review (the doc + the wiring)

- The doc: `dev/architecture.md` §Combat Integration — documents auto-farm's
  `attackBase(tileInfo) → POST /api/combat/infantry { targetUsername, unitIds }` and the
  stat updates. The engine still matches this wiring (`utils/autoFarmEngine.ts:1150`).
- The engine: `/api/combat/infantry` → `executeInfantryAttack` (session attacker,
  presence-checked, self-attack blocked) — LIVE; the two INFANTRY rows prove real use.
- The gap: manual play has NO entry point — `CombatAttackModal` (unit-picker UI for
  infantry attacks) is exported but rendered nowhere, and its base-attack branch targets
  `/api/combat/base`, an endpoint that never existed. Base raids flow through
  `/api/combat/attack` instead. Options recorded in FID-20260914-007 §4 (operator
  decision; not implemented this session).

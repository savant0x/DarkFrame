# SESSION-2026-09-14-006 — Battle-logs ~40 s load fixed (blob-shipping)

**Date:** 2026-09-14 · **Protocol:** ECHO v0.1.2 single-agent

**Task source:** operator report — "clicking attack logs takes about 40 seconds until it
loads, something is wrong there. `http://localhost:3002/game/battle-logs/attack`"

---

## Intent (logged before implementation — Law 8)

Diagnose the 40-second battle-logs page load by measurement, fix the root cause with the
minimal change, and prove the fix with before/after timings and green gates. No speculative
optimization; keep the API response contract intact for the page's consumers.

## Diagnosis chain (all measured, scratch probes deleted after use)

1. Page fetch pattern: single `GET /api/battle-logs?...&limit=20` on mount — clean.
2. API direct (nonexistent user): 0.54 s — fast. Page unauthenticated: 307 redirect.
3. DB probe: table = 26 rows; heap 48 kB, **TOAST 1,352 kB (91%)**; indexes all present.
4. `EXPLAIN (ANALYZE, BUFFERS)`: 0.139–0.152 ms, index scan, 9 buffers — SQL is NOT slow.
5. Node-side `SELECT *` for 'fame' (19 rows): **18.5 / 22.8 / 21.1 / 16.9 s — every run**;
   slim columns on the same predicate: **66 ms**. → fetch-side TOAST decompression.
6. Column sizes: `attacker_units` ≈ 48.7 KB, `defender_units` up to ~125 KB (compressed),
   `rounds` ~232 B. The route's `db.select()` ships all 38 columns; its mapping reads 27 —
   never the three giants. (Blob-shipping class of FID-20260911-043.)
7. The page's dev strict-mode double-fetch doubles the ~19 s — the user's ~40 s.

## Fixes shipped (app/api/battle-logs/route.ts, contract test extended)

| # | Fix | Detail |
| --- | --- | --- |
| 1 | Explicit 27-column projection | Excludes `attackerUnits`/`defenderUnits`/`rounds`; includes the mapping's every consumed key (tsc caught two initially-missed losses columns — fixed) |
| 2 | `summarizeCapturedUnits()` | Raw captured arrays held FULL unit documents (one log: 4,400+ entries, 242 KB); the page renders only `.length`. Collapsed to per-type `{unitType, count}` groups — counts truthful, "unit group(s)" finally means groups. Module-local (route files may only export handlers/config — caught by Next's route type contract) |
| 3 | `land-mines` honest empty envelope | The header always documented "no writer yet → honest empty set"; previously the infantry-only `battleType` filter let the tab serve mislabeled attack/defense logs. Now short-circuits with zero DB queries |

Response contract kept (envelope + all page-read fields); the route's only consumer is the
battle-logs page (grep-verified).

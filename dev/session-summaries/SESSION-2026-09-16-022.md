probe."** Procedure block (in the Law 13 style): name the artifact the closure claims →
probe it fresh with pasted tool output → confirm it *does the thing* (a stub is not a
closure) → only then write the disposition, citing the probe in the cell. A failed probe
leaves the row open with the mismatch recorded. Disposition cells are never cloned from
other rows (cloning inherits staleness). Reverse direction included: an `Open` row with no
recent probe is a hypothesis — surveys must probe before acting.

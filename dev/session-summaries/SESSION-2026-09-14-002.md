## Residual defects (FID-20260914-003 §2; all file:line verified)

1. **HIGH — buyout forfeits the outbid leader's escrow.** `placeBid` escrows every bid;
   the release fires only inside `placeBid` (outbid). `buyoutAuction` charges the buyer,
   pays the seller, sets `Sold` — and never returns the previous leader's `currentBid`
   metal. Silent player loss on every bid-then-buyout auction.
2. **HIGH — TradeableItem listings accepted but can never deliver.** Validation is
   quantity-only (lock = `{}`), `transferAuctionItem`'s branch is an empty TODO returning
   success, the modal ships the option (`CreateListingModal.tsx:110-112`), the create
   route + schema accept it. Buyer pays, receives nothing, seller keeps the goods.
3. **MEDIUM — unit escrow is a silent no-op.** The positional-operator
   `$set: { 'units.$[unit].locked': true }` maps on doc-tables only; `players` has no
   `doc` column, so the lock write is dropped — double-listing is possible until
   settlement self-heals (TRANSFER_FAILED → refund).
4. **LOW — `my-bids` sorts on the stale dot-path `bids.timestamp`** (domain field is
   `bidTime`); the shim filters unmapped sort keys, so ordering is DB-natural.
5. **INFO — `$pull` with an object operand** (`{ units: { unitId } }`) relies on
   `jsonb - jsonb` element semantics unconfirmed by code reading; flagged for a live probe
   at implementation (non-blocking once unit escrow lands).

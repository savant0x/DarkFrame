## Intent (logged before implementation)

Create the four companion artifacts referenced by `dev/echo-v0.1.2-single-agent.md` so the single-agent protocol is
executable rather than aspirational:

1. `protocol.config.yaml` — the machine-readable `single_agent.protocol` contract: verification commands taken from
   the project's own `package.json` scripts (`npx tsc --noEmit`, `npm run lint`, `npm run test:ci`), canonical paths,
   FID rules, Perfection Loop circuit breakers, scope markers, and version-control constraints (no agent git
   execution).
2. `templates/FID-TEMPLATE.md` — the exact FID template, with the required metadata fields. Design decision: the
   protocol text lists `Author` among required fields, but the protocol's Document Signing & Attribution rule
   forbids `Author:` fields in repository artifacts. The attribution rule is explicit and non-negotiable, so the
   template omits the field and documents the omission. Alternative considered (keep `Author` and fill it with the
   operator name) was rejected: it would violate the attribution rule on every future FID.
3. `SCOPE.md` — the scope audit trail, seeded with this session's approved items.
4. `dev/session-summaries/` — conventions doc (`README.md`) plus this record.

No application code is touched. Complexity: simple-task routing (small, single-file artifacts, no new APIs).

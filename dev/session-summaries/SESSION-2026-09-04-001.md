## What was done (all committed in `2bdd48c`, pushed to `savant0x/DarkFrame`)

1. **Login loop — two stacked root causes, both fixed:**
   - `app/api/auth/session/route.ts` used fallback secret `'your-secret-key-change-in-production'`; login/middleware/WS used `'darkframe-secret-change-in-production'`. All four JWT sites now import shared **`lib/jwt.ts`** (`JWT_SECRET` + Edge-safe `JOSE_SECRET`). Divergence is structurally impossible now.
   - `GameContext` runs its session check **once per provider mount** (root layout). Login's soft `router.push('/game')` never remounted it → GamePage saw `!player` → bounce to `/login` → infinite loop. `app/login/page.tsx` now hard-navigates (`window.location.href = '/game'`).
   - Login inputs: `autocomplete="email"` / `autocomplete="current-password"` (Chrome echoed the password `value=` into console DOM logs without it).
2. **Session/activity trackers rewritten to real Postgres** (`lib/sessionTracker.ts`, `lib/activityLogger.ts`): previously inserted Mongo docs through the shim → `null value in column "id"` crash on **every login**. Migration **`0006_session_analytics.sql`** (player_sessions: session_id/start_time/end_time/duration/actions_count/resources_gained_*/ip_address; player_activity: session_id/metadata jsonb — all nullable for legacy auth rows) **applied to the live DB** (verified via information_schema). All export signatures preserved; `activityLogService` keeps its separate `details` jsonb lane.
3. **Shim hardening (class-wide), `lib/mongodb.ts`:**
   - `insertOne`/`insertMany` auto-generate the 24-char `id` PK (accepts doc `id`/string `_id`, reflects generated id onto caller's doc like Mongo) — null-id insert crash class dead everywhere.
   - `buildWhere` with a **non-empty** filter whose keys map to zero columns now builds `sql\`false\`` (match nothing) instead of silently match-everything — whole-table update/delete hazard closed. Empty `{}` still matches all (Mongo semantics; system-reset/seeds rely on it).
4. **CSP:** the *duplicate* policy in `next.config.js` was the font blocker (middleware's already allowed fonts). Both now permit `fonts.googleapis.com` styles + `fonts.gstatic.com` fonts. Orbitron loads.
5. **Flaky test fixed:** `lib/harvestService.test.ts` asserted time-until-reset `< 12h`, but reset is next **midnight** ⇒ `< 24h` (old bound only held in afternoons; failed at 4 AM). Assertion now matches the function's actual contract.
6. **Environment landmine found (SCOPE #23):** operator shell exports `PORT=0` → `server.ts`'s `process.env.PORT || '3000'` binds port 0, banner prints `localhost:0`, nothing listens. Workaround: launch `PORT=3002 npm run dev:server`. Permanent fix needs operator-side env decision.

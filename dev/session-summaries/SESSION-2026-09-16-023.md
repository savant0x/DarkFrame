## Findings (full detail: `dev/audits/FEATURE-SURVEY-2026-09-16.md`)

- **P0 — player-side broken UI (new discovery, not in any ledger row):** three endpoints
  UI panels call **do not exist**: `/api/discoveries` (DiscoveryLogPanel errors on open —
  only `discovery/status` exists), `/api/friends/online` (FriendsList always fails), and
  the friends block flow (FriendActionsMenu). This is the player-side sibling of the #22
  admin-modal fix — that sweep covered admin only. Backends exist (`discoveryService`,
  `friendsService`); this is contract re-wiring, not new systems.
- **P1 — the recorded product call:** surface sabotage in `WMDIntelligencePanel`
  (server fully live since -007: repaired route, owner-derived targets, void at commit).
  The panel already lists missiles/batteries/research rows — a sabotage tab with
  target → victim preview → fire flow fits naturally.
- **P2 — latent systems with zero UI:** clan research (`contribute`/`unlock` — a whole
  tech tree unreachable), territory capture (`clan/warfare/capture`), generic PvP battle
  (`battle/attack`, seams live per -008), shrine sacrifice/extend/status, tutorial
  completion.
- **P3 — inert-by-design:** specialization mastery (zero bonus consumers, per the
  2026-09-14 audit) — wire bonuses or hide the UI.
